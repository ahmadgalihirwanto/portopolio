PORTOFOLIO AHMAD GALIH IRWANTO
==============================

CARA MENJALANKAN
Ekstrak ZIP, lalu buka index.html di browser. Tanpa database/framework (HTML, CSS, JS murni).
Font Google Fonts butuh internet.

YANG PERLU KAMU ISI
1. CV      : taruh file PDF di assets/CV.pdf  (tombol Download CV sudah terhubung)
2. Email   : cari "emailkamu@example.com" di index.html (3 tempat), ganti email aktif
3. GitHub / LinkedIn : di index.html bagian .socials, isi href lalu hapus atribut hidden
4. Foto    : assets/foto-profil.jpg (sudah berisi foto kamu)
5. Proyek  : cek kembali tag teknologi di tiap kartu proyek agar sesuai implementasi asli.
             Ilustrasi proyek berupa mockup CSS, bisa diganti screenshot asli.
6. Warna   : ubah variabel di bagian :root pada style.css (--blue = #3568ED)
